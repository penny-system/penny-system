# Troubleshooting Log

## 2026-02-20 — DB path confusion
**Symptom:** approve.py says DB not found at Trader_bot\output\trader.sqlite  
**Cause:** Running from different working directory or wrong DB_PATH default  
**Fix:** Use --db-path output\trader.sqlite or set config.DB_PATH to output\trader.sqlite

## 2026-02-20 — suggested_qty duplicate column
**Symptom:** sqlite3 OperationalError: duplicate column name suggested_qty  
**Cause:** Migration already applied  
**Fix:** Treat migration as idempotent; don’t re-add column.

## 2026-02-20 — fill_suggested_qty rowid error
**Symptom:** IndexError: No item with that key (rowid)  
**Cause:** SELECT didn’t include rowid alias or row_factory mismatch  
**Fix:** Query rowid explicitly or use cursor fetch tuples and index.

## 2026-02-20 — PURSE=0.0 in fill_suggested_qty
**Symptom:** qty outputs 0 even with BUYs  
**Cause:** Script reading wrong config key or defaulting to 0  
**Fix:** Ensure TRADE_PURSE_USD is used; verify config import and values.

## 2026-02-21 — Telegram chat id missing for scheduled notify
**Symptom:** TELEGRAM_CHAT_ID is None; scheduled messages fail  
**Fix:** Set TELEGRAM_CHAT_ID to numeric chat id in config.py (no quotes).

## 2026-02-21 — Task Scheduler password prompt (PIN not accepted)
**Symptom:** Task Scheduler asks for password; user only knows PIN  
**Fix:** Create task using “Run only when user is logged on”.
