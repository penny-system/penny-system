# Architecture Decisions (Do Not Re-open Unless Needed)

## News + AI design
- Deterministic engine drives decisions.
- OpenAI is decision-support/QC only (not primary driver).
- Morning run: OpenAI always runs on top BUYs.
- Intraday: OpenAI standby triggers only for:
  - Trigger A: High-severity event detected
  - Trigger C: Conflict (base risk low but red flags present)

## News sources
- Use Marketaux (paid) for ticker news.
- Add SEC EDGAR + Press Release RSS for high-signal events.
- Keep IBKR historical headlines keyword scan as fallback if desired.

## Outputs
- OpenAI results stored to DB fields (news_action/multiplier/score/flags).
- No need to append narrative news summaries to brief.txt.
